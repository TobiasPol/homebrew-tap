# TobiasPol's Homebrew tap

Homebrew casks for my macOS apps.

## Overtone

A system-wide equalizer for the macOS menu bar. See the
[Overtone repository](https://github.com/TobiasPol/overtone) for features and usage.

```bash
brew install --cask tobiaspol/tap/overtone
```

Update or remove it:

```bash
brew upgrade --cask overtone
brew uninstall --zap --cask overtone
```

Releases aren't notarized yet. The first time you open Overtone, macOS blocks it: go to
**System Settings → Privacy & Security** and click **Open Anyway**.
