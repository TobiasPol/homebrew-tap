# homebrew-tap

## Overview
Homebrew tap (`brew tap tobiaspol/tap`) holding casks for TobiasPol's macOS apps.

## Tech Stack
- Language: Ruby (Homebrew cask DSL)

## Commands
- `brew style Casks/overtone.rb` — Lint a cask
- `brew audit --cask tobiaspol/tap/overtone` — Audit after tapping

## Architecture
- `Casks/overtone.rb` is generated by `scripts/update-cask.sh` in the Overtone repository
  (run by its Release workflow when `TAP_GITHUB_TOKEN` is set). Edit the template there, not here.

## Environment Variables
None.
